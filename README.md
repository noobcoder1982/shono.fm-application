# shono.fm — Official Website

> Precision Audio Archive & Desktop Music Player web experience.

Official website for **shono.fm**, an open-source desktop music player for Windows and macOS. Explore interactive 3D album artwork, synchronized lyrics, custom visualizers, themes, and direct release downloads.

---

## ⚡ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler**: [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- pnpm (recommended) or npm

### Installation

```bash
# Clone the repository
git clone https://github.com/noobcoder1982/shono.fm-application.git
cd shono.fm-application

# Install dependencies
pnpm install
# or
npm install
```

### Development

```bash
pnpm dev
# or
npm run dev
```

The application will start at `http://localhost:8443` (or the configured `$PORT`).

### Production Build

```bash
pnpm build
# or
npm run build
```

Preview the production build locally:

```bash
pnpm preview
# or
npm run preview
```
